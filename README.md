# Nubo : The next evolution of tsboard

`tsboard` 프로젝트를 기반으로 완전히 새롭게, 그러나 여전히 그 유산을 잇는 `Nubo`를 소개합니다.
`Nubo`는 기존 `tsboard`의 DB 구조와 백엔드를 그대로 활용하면서, `SPA`(Single Page Application)로 제작된 이전 버전의 한계를 극복하기 위해 `Nuxt4` 기반의 `SSR`(Server Side Rendering) 방식으로 개발되었습니다.

커뮤니티 사이트의 서버 운영 효율을 높이고 검색 엔진 최적화를 강화해 더 많은 유입을 목표로 설계했습니다.
기존 `tsboard`에서 `Nubo`로의 완전한 전환은 26년 2월 말 예정이며, 그전까지는 기존 프로젝트의 유지보수와 병행할 예정입니다.

이미 `tsboard` 프로젝트를 진행하면서 백엔드를 성공적으로 교체했던 경험을 바탕으로, 이번 SPA에서 SSR로의 전환도 순조롭게 이루어질 것으로 기대합니다.
앞으로 `Nubo` 프로젝트가 기존 `tsboard` 프로젝트를 성공적으로 계승해 한 단계 더 나아간 커뮤니티 빌더가 될 수 있도록 많은 응원 부탁드립니다!

프로젝트 이름 Nubo는 Nuxt3 + Board를 합친 단어로, 발음하기 쉽게 새로 지은 이름입니다. [nubohub.org](https://nubohub.org) 사이트에서 자세히 만나보실 수 있도록 준비하겠습니다!
