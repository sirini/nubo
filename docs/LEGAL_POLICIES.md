# 서비스 정책 운영

NUBO 기본 정책은 `/terms`, `/privacy`, `/disclaimer`에 공개된다. 기본 레이아웃의
햄버거 메뉴에 있던 약관·개인정보 링크는 공통 하단으로 이동했다. 하단은 스킨 바깥의
기본 Nuxt 레이아웃에 있어 레이아웃 스킨 교체 시에도 유지된다.

## 운영처 설정

`env.sample`의 다음 공개 환경 변수를 `.env`에 지정한다. prebuilt 실행 시에도 적용된다.

- `NUXT_PUBLIC_LEGAL_OPERATOR`: 실제 운영 주체. 미지정 시 사이트 이름.
- `NUXT_PUBLIC_LEGAL_OFFICER`: 개인정보 보호 담당자·부서. 미지정 시 운영 주체.
- `NUXT_PUBLIC_LEGAL_EMAIL`: 문의·권리침해 접수 메일. 미지정 시 기존 관리자 메일.
- `NUXT_PUBLIC_LEGAL_ADDRESS`: 공개 연락 주소. 빈 값이면 생략.
- `NUXT_PUBLIC_LEGAL_PROCESSING_DETAILS`: 실제 수탁자·업무·항목·보유기간과 국외 이전의
  국가·연락처·시기·방법·근거·거부 방법, 로그·백업 보존기간·파기주기를 구체적으로 기재.
  따옴표로 감싼 여러 줄 입력을 지원하며 HTML로 실행하지 않는다.

이 값들은 **공개 정보**다. 비밀키·내부 서버 주소·사내 비공개 연락망을 넣지 않는다.
수탁자·국외 이전·로그·백업 정책은 배포마다 달라 코드에서 사실을 추측해 고정하지 않았다.
상세가 비어 있으면 미등록 사실과 문의 경로를 표시한다. 실제 처리를 시행하기 전 운영자가
해당 현황을 공개해야 한다. 공통 문서만으로 개별 배포의 법적 의무가 모두 충족되지는 않는다.
약관 페이지를 표시하는 기능이며 별도의 가입 동의 수집·동의 버전 저장 시스템은 이번에 추가하지 않았다.

## 개정과 이력

본문은 `app/data/legal/*.json`, 공통 화면은 `app/components/legal/LegalDocument.vue`다.
시행일·개정 요약·본문·목차를 함께 표시하고 버전 주소는 `?version=YYYY-MM-DD` 형식이다.
알 수 없는 버전은 404로 처리한다. 과거 문서에는 검색 제외와 이전 문서 안내를 붙인다.

개인정보 2026-11-09 JSON 보존본과 기존 개인정보(2026-09-06)·약관(2026-08-21) Vue 전문은 `components/legal/archive`에
보존했다. 과거 전문의 기존 표현은 현행 정책을 의미하지 않는다. 과거 원문이 참조하던 사이트명과
연락처는 현재 runtime 설정이므로 그 점을 이전 문서 화면에 명시한다.

다음 개정 시 현행 JSON을 날짜별 보존본으로 먼저 복사하고 버전 선택 목록에 추가한 뒤
현행 문서를 변경한다. 운영처의 `.env` 상세·연락처를 바꾸는 경우에도 당시 공개한 문서와 설정의
공개 값만 별도 보존하고 변경 사유·시행일을 공지한다. Git 기록만을 공개 이력으로 대신하지 않는다.
변경은 원칙적으로 7일 전, 불리하거나 중요한 약관 변경은 30일 전에 고지하도록 본문에 명시했다.
이번 기본 문서의 날짜는 코드 반영일이며, 각 운영처가 기존 회원에게 적용할 때에는 실제 공지·시행
일정과 필요한 동의 절차에 맞춰 조정해야 한다.

## 구현 대조와 참고

- GOAPI의 업로드·EXIF 저장, 계정 연결 데이터 삭제 및 외부 연동 설정을 대조했다.
  웹 전체 경로에서 GPS 제거를 보장하지 않으므로 그렇게 기재하지 않았다.
- 실명 인증·DI 보존·일률적인 탈퇴 후 30일 보존·24시간 관제 등 구현에 없는 기능을 주장하지 않는다.
- 사용자가 제공한 클리앙의 세 문서는 구성 참고로 사용했다. 실명·생년월일 수집, 보관기간,
  무통지 변경, 광범위 면책 및 전속 관할 문구는 그대로 옮기지 않았다.
- [개인정보보호위원회 안내서 목록: 개인정보 처리방침 작성지침(2026.4.)](https://pipc.go.kr/np/cop/bbs/selectBoardList.do?bbsId=BS217&mCode=I030010000)
- [개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법)
- [약관의 규제에 관한 법률](https://www.law.go.kr/법령/약관의규제에관한법률)

API·DB·GOAPI 바이너리 변경은 없다. 실제 운영자 정보와 처리 상세의 정확성 및 조직별 보안 규정은
배포 운영자가 확인한다.

## 검증

Node 26에서 lint(기존 경고 49개), typecheck, 전체 156개 테스트 및 production build 통과.
생성한 서버를 production 모드로 실행해 현행 세 문서·이전 두 문서의 HTTP 200,
미등록 버전 HTTP 404, runtime 환경 변수 주입과 공통 footer 포함을 확인했다.
실제 GOAPI에 연결한 가입·사진 업로드·신고의 운영 QA나 법률 적합성 인증을 의미하지 않는다.

현재 개인정보처리방침은 2026-11-10 개정본이다. 실제 외부 연동 상태와 로그 정책은
백엔드 상태 조회를 통해 표시하며 자세한 기록·보관·CSV 제출 기준은 `SECURITY_LOGS.md`를 따른다.

기본·고급 홈은 자체 하단과 사이드 영역에 공통 `LegalLinks`를 사용한다. 해당 홈에서는
바깥 레이아웃 footer를 중복 표시하지 않고, 다른 페이지·사용자 홈 스킨은 공통 footer를 유지한다.
관리자 감사는 단기 운영 로그와 분리해 기본 732일 보존·무결성 확인·CSV 목적·월별 확인을 제공한다.
