# NUBO v1.2.30

NUBO v1.2.30은 기존 서버 재설치 hotfix와 함께 v1.2.28에서 최신 버전으로 직접 update할 수 있도록
템플릿 호환 경로를 보완한 통합 운영 hotfix입니다. v1.2.29의 fresh install 수정사항을 모두 포함하며,
운영 중인 v1.2.28 사이트는 v1.2.30으로 바로 업데이트하는 것을 권장합니다.

## 주요 변경사항

### 기존 서비스 실행 계정 보존

- 설치된 GOAPI unit의 `User`와 `Group`을 재설치 기본값으로 사용합니다.
- 운영자가 `--user`·`--group`을 명시하면 해당 값을 우선합니다.
- root로 운영하던 사이트가 갑자기 `nubo` 계정으로 바뀌어 기존 업로드 디렉터리 권한 검사에서
  중단되는 일을 막습니다.

### NVM Node.js와 systemd 보안 설정 호환

- Node.js가 `/root` 또는 `/home` 아래에 있을 때 Web unit의 홈 접근을 읽기 전용으로 허용합니다.
- 시스템 경로의 Node.js를 쓰는 설치에서는 홈 디렉터리를 완전히 숨깁니다.
- 이 `ProtectHome` 한 줄은 설치 시 Node 경로에 따라 달라지는 정책으로만 인정해 v1.2.28의 엄격한
  템플릿 변경 차단을 통과하며, 나머지 systemd·Nginx 템플릿 변경은 계속 거부합니다.

### 재설치가 실제 새 런타임을 시작

- 기존 환경 파일의 비밀값과 운영 설정은 보존하고 `GOAPI_VERSION`·`NUXT_PUBLIC_VERSION`만 현재
  릴리스에 맞게 원자적으로 갱신합니다.
- 이미 active인 `nubo.service`가 있어도 GOAPI와 Web을 명시적으로 재시작합니다.
- 재시작 또는 readiness가 실패하면 환경 파일의 버전 변경을 원래 내용으로 복원합니다.

## 업데이트 방법

```bash
nuboctl update --dry-run
nuboctl update
nuboctl status
```

Nginx·TLS와 기존 업로드 디렉터리의 소유권·권한은 계속 운영자가 관리하며 nuboctl은 자동 변경하지
않습니다.
