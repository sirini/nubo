# NUBO v1.3.1

- `./bin/nubo search`와 `info skins/<key>`로 공식 Market의 공개 스킨과 현재 checkout 호환성을 읽기
  전용으로 확인할 수 있다. 평문·warm-tone TTY·JSON 출력 계약을 함께 제공한다.
- `install skins/<key>`는 package SHA-256과 안전한 압축 경로를 검증하고 파일별 영수증을 남긴다. 관리
  중인 스킨은 로컬 변경이 없을 때만 상위 버전으로 원자적으로 교체하며 `--dry-run`을 지원한다.

NUBO v1.3.1은 Source Mode 운영자를 위한 새 `./bin/nubo`의 첫 릴리스다. v1.2의 서버 lifecycle
자동화를 이어가지 않고 검증된 공식 runtime을 현재 작업 공간에 공급하는 작은 도구로 다시 시작한다.

## 새 NUBO CLI

- Bubble Tea v2와 Lip Gloss v2 기반의 warm-tone 대화형 시작 화면과 진행 상태를 제공한다.
- 비대화형 터미널에서는 평문으로 동작하며 `--plain`, `--json`, `--yes`, `--dry-run`을 지원한다.
- tracked `./bin/nubo` launcher는 첫 실행에 Linux amd64 CLI와 SHA-256을 검증해 `.nubo/bin/nubo`에
  준비한다.
- `download`는 현재 checkout descriptor가 고정한 GOAPI commit과 API contract만 허용한다.
- `update`는 공식 checksum, Linux amd64 ELF와 실행 버전을 확인한 뒤 CLI 자체만 원자적으로 교체한다.

## Runtime 경계

- 공식 runtime asset은 `bin/goapi`, `lib`, `licenses/sharp-libvips`와 machine-readable manifest를
  포함한다.
- 외부 archive와 모든 내부 파일의 SHA-256, 압축 경로, 파일 형식과 필수 libvips 변형을 검증한다.
- 기존 runtime은 staging 검증이 모두 끝난 뒤 같은 파일시스템에서 교체하며 중간 실패 시 복구한다.
- Git, Nuxt 빌드, DB migration, tmux·PM2·systemd와 실행 중인 서비스를 자동으로 변경하지 않는다.
- 완료 화면은 데이터베이스 백업, 필요한 경우의 GOAPI migration, Web 빌드와 운영자 소유 재시작을
  다음 작업으로 안내한다.

## 공식 asset

- `nubo-linux-amd64`와 SHA-256
- `nubo-runtime-1.3.1-linux-amd64.tar.gz`와 SHA-256

두 asset은 Ubuntu 22.04와 24.04에서 bootstrap·runtime 배치와 libvips 동적 링크를 검증한다.
