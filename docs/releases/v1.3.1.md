# NUBO v1.3.1

NUBO v1.3.1은 소스 checkout을 직접 빌드·실행하는 운영자를 위한 새 `./bin/nubo`의 첫 릴리스다.
v1.2의 서버 lifecycle 자동화를 이어가지 않고, 검증된 공식 runtime과 Market 스킨 소스를 현재 작업
공간에 공급하는 작은 도구로 다시 시작한다.

## 커뮤니티와 작품 활동

- `nubo-advance-home`은 카드형 최신 피드, 미디어 확대 보기와 게시판 rail을 제공한다.
- JWT 본인 전용 `GET /board/my/studio`와 `nubo-advance-profile` 작품 스튜디오를 추가했다. 게시판별
  작품·사진·조회·좋아요·댓글 누계와 네 가지 정렬·paging 목록을 제공하며 타인의 통계는 조회할 수 없다.
- 게시글과 댓글 좋아요는 요청 성공 직후 화면의 숫자와 상태에 반영된다.
- advance gallery·blog와 basic blog에서도 작성자와 게시판 권한 관리자가 게시글을 바로 삭제할 수 있다.
  basic board·gallery·trade의 기존 관리 메뉴와 동일한 권한·확인·API 계약을 사용한다.

## NUBO Market

- `./bin/nubo search`와 `info skins/<key>`로 공식 Market의 공개 스킨과 현재 checkout 호환성을 읽기
  전용으로 확인할 수 있다. 평문·warm-tone TTY·JSON 출력 계약을 함께 제공한다.
- `install skins/<key>`는 package SHA-256과 안전한 압축 경로를 검증하고 파일별 영수증을 남긴다. 관리
  중인 스킨은 로컬 변경이 없을 때만 상위 버전으로 원자적으로 교체하며 `--dry-run`을 지원한다.
- `validate|pack skins/<key>`는 로컬 스킨을 실제 Market 계약으로 검사하고, 동일 source에서 같은
  SHA-256을 갖는 source package를 만든다. 업로드와 publish는 수행하지 않는다.
- 관리자 스킨, NUBO README와 Market 안내는 모두 `./bin/nubo ... skins/<key>` 계약을 사용한다. 설치
  뒤 Nuxt 빌드와 tmux·PM2 재시작은 운영자가 직접 수행한다.

## 새 NUBO CLI

- Bubble Tea v2와 Lip Gloss v2 기반의 warm-tone 대화형 시작 화면과 진행 상태를 제공한다.
- 비대화형 터미널에서는 평문으로 동작하며 `--plain`, `--json`, `--yes`, `--dry-run`을 지원한다.
- tracked `./bin/nubo` launcher는 첫 실행에 Linux amd64 CLI와 SHA-256을 검증해 `.nubo/bin/nubo`에
  준비한다.
- `download`는 현재 checkout descriptor가 고정한 GOAPI commit과 API contract만 허용한다.
- `update`는 공식 checksum, Linux amd64 ELF와 실행 버전을 확인한 뒤 CLI 자체만 원자적으로 교체한다.

## Runtime 경계

- 공식 runtime asset은 `bin/goapi`, `lib`, `licenses/sharp-libvips`와 machine-readable manifest를
  포함한다.
- 외부 archive와 모든 내부 파일의 SHA-256, 압축 경로, 파일 형식과 필수 libvips 변형을 검증한다.
- 기존 runtime은 staging 검증이 모두 끝난 뒤 같은 파일시스템에서 교체하며 중간 실패 시 복구한다.
- Git, Nuxt 빌드, DB migration, tmux·PM2·systemd와 실행 중인 서비스를 자동으로 변경하지 않는다.
- 완료 화면은 데이터베이스 백업, 필요한 경우의 GOAPI migration, Web 빌드와 운영자 소유 재시작을
  다음 작업으로 안내한다.

## 공식 asset

- `nubo-linux-amd64`와 SHA-256
- `nubo-runtime-1.3.1-linux-amd64.tar.gz`와 SHA-256

runtime은 GOAPI `cb485a4`와 API contract v1, libvips 8.18.3을 고정한다. 작품 스튜디오는 기존 테이블과
인덱스를 사용하므로 DB migration은 필요하지 않다. 두 asset은 Ubuntu 22.04와 24.04에서
bootstrap·runtime 배치와 libvips 동적 링크를 검증한다.
