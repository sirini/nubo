# NUBO v1.2.29

NUBO v1.2.29는 기존 서버에서 `nuboctl install`을 다시 실행할 때 서비스 실행 계정과 Node.js 경로를
잘못 다뤄 애플리케이션이 시작되지 않던 문제를 바로잡는 통합 운영 hotfix입니다.

## 주요 변경사항

### 기존 서비스 실행 계정 보존

- 설치된 GOAPI unit의 `User`와 `Group`을 재설치 기본값으로 사용합니다.
- 운영자가 `--user`·`--group`을 명시하면 해당 값을 우선합니다.
- root로 운영하던 기존 사이트가 갑자기 `nubo` 계정으로 바뀌어 root 소유 업로드 디렉터리 검사에서
  중단되는 일을 막습니다.

### NVM Node.js와 systemd 보안 설정 호환

- Node.js가 `/root` 또는 `/home` 아래에 있을 때 Web unit의 홈 접근을 읽기 전용으로 허용합니다.
- 시스템 경로의 Node.js를 쓰는 일반 설치에서는 기존처럼 홈 디렉터리를 완전히 숨깁니다.
- `ProtectSystem=strict`, `NoNewPrivileges`와 홈 쓰기 차단은 그대로 유지합니다.

### 재설치가 실제 새 런타임을 시작

- 기존 환경 파일의 비밀값과 운영 설정은 보존하고 `GOAPI_VERSION`·`NUXT_PUBLIC_VERSION`만 현재
  릴리스에 맞게 원자적으로 갱신합니다.
- 이미 active인 `nubo.service`가 있어도 GOAPI와 Web을 명시적으로 재시작합니다.
- 재시작 또는 readiness가 실패하면 환경 파일의 버전 변경을 원래 내용으로 복원합니다.

## 운영 경계

- Nginx와 TLS 설정은 계속 운영자가 전적으로 관리하며 `nuboctl install`은 `/etc/nginx`를 읽거나
  변경하지 않습니다.
- 기존 업로드 디렉터리의 소유권과 권한도 자동 변경하지 않습니다.
- 공식 prebuilt 지원 범위는 Ubuntu 22.04 이상 amd64, Node.js 22 이상, systemd, MySQL/MariaDB 단일
  서버입니다.
