# NUBO v1.4.0

1.3.2에서 마이너 버전을 올렸다. 웹과 GOAPI를 함께 업데이트한다. DB migration은 없다.
기존 `deploy/release-sources.json`의 1.3.2 다운로드 자산은 이번 소스를 포함하지 않는다.
공식 1.4.0 자산 발행 전에는 최신 소스와 공식 GOAPI 빌드 스크립트를 사용한다.

- 관리자 → 관리자 콘솔(`/admin/logs`): 방문자 접속, 단기 운영, 관리자 감사 기록 선택.
- 비로그인은 IP 원문, 로그인은 서버가 인증한 UID와 IP 원문을 시각·페이지 경로와 보관한다.
  첫 문서 요청은 Nuxt 서버에서, 이후 SPA 페이지 이동·로그인 상태 변경은 브라우저에서 기록한다.
- 관리자 화면 방문은 기존 HMAC 연결·봉인된 감사 저장소에도 기록한다. 관리자 API 감사는 유지한다.
- UTC 날짜별 100건 조회·전체 날짜 CSV와 제출 목적 감사, 일/월/연 페이지 접속 그래프.
  통계는 순 방문자 수가 아니며 보존기간 밖 데이터는 포함하지 않는다.
- 방문자·관리자 감사는 관리자 명시적 삭제까지 계속 보관한다. 기존 90일·732일 변수는 적용하지 않는다.
  과거 UTC 날짜별 영구 삭제에 날짜 재입력·확인을 요구하며 삭제 사유·실행 전후를 당일 감사에 남긴다.
  단기 운영 로그만 기본 7일 자동 만료를 유지한다.
- 개인정보처리방침의 계속 보관·명시적 삭제 안내와 2026-11-10 전문 보존. 실제 공지·시행일은 운영처 설정을 적용한다.

웹과 GOAPI의 `NUXT_PUBLIC_VERSION`·`GOAPI_VERSION`을 1.4.0으로 변경한다.
실제 방문자 IP를 얻으려면 양쪽의 `NUBO_TRUSTED_PROXY_CIDRS`와 Nginx 헤더 덮어쓰기가 필요하다.
원문 기록은 하루 100MiB 한도이며 누락·저장 오류를 콘솔에서 확인한다. 브라우저 차단·네트워크 실패,
정적 캐시·우회 접속까지 완전하게 증명하는 서버 접근 로그는 아니므로 보안부서 제출에는 Nginx 등
독립 기록과 함께 사용한다. 기존 기록을 소급 생성하지 않는다. 지역 통계는 위치 DB 연동 전까지 제공하지 않는다.

자세한 보관·제출·프록시 설정은 [운영 로그 문서](../SECURITY_LOGS.md)를 따른다.

`TestGetStudioAggregatesAndPagesOnlyRequestedUserPosts`와 `TestPostReactionRejectsViewRestrictions`
실패는 변경 전 `b638c09`에서도 재현했다. production HTTP에서는 임시 백엔드로 현행·이전 정책의
응답과 SSR 경로 기록·query 제외를 확인했다. 운영 서비스에 배포하지 않았다.
