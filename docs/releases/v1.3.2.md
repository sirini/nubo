# NUBO v1.3.2

v1.3.2는 운영 중 Node 메모리가 누적되던 문제를 수정하고, 사진의 첫 화면 품질과 오류 화면을
개선한 릴리스다. v1.3.1 이후 추가한 영구 업적, 알림 바로가기, 1:1 메시지 읽음 표시와 모바일
클라이언트를 위한 공통 GOAPI 변경도 함께 포함한다.

## 운영 안정성

- `npm start`가 `.env`를 읽고 `NODE_ENV=production`으로 실행한다. production 설정이 없을 때
  `vee-validate`의 개발용 전역 폼 목록이 SSR 화면을 계속 보관하던 메모리 누수를 방지한다.
- HTML 정제에 사용하는 DOMPurify hook을 요청 처리 뒤 해제해 전역 hook 누적을 막는다.
- 빌드한 로그인 화면을 100회 예열한 뒤 1,000회 요청하고 GC 이후 메모리 증가를 검사하는
  `npm run test:ssr-memory`를 추가했다. 공식 릴리스 검사에서도 실행한다.

## 사진과 공통 테마

- advance home·blog·gallery의 목록 이미지를 작은 썸네일 대신 기존 고해상도 프리뷰로 표시한다.
  홈의 첫 미디어와 갤러리의 첫 네 장을 우선 로드해 처음 보이는 사진을 선명하게 보여준다.
  이미지 트래픽은 이전보다 늘 수 있다.
- `nubo-basic-error`에 웜톤 라이트·다크 테마, 상태별 안내와 홈 복귀 동작을 적용했다.
- 기본 색상 토큰을 공통 CSS로 옮겨 일반 레이아웃이 없는 오류 화면에도 동일하게 적용한다.
  커스텀 레이아웃은 기존 `app/skins/nubo-basic-layout/theme.css`에서 색상을 덮어쓸 수 있다.

## 업적과 커뮤니티 활동

- 첫 게시글·첫 댓글 등 영구 업적을 저장하고, 프로필·사진 상세·댓글 작성자 옆에 표시한다.
  새로 받은 업적은 한 번의 축하 안내로 확인할 수 있다.
- 관리자는 업적을 생성·수정하고 사용자에게 수동 수여할 수 있다. 관리자 API 프록시도 보완했다.
- 알림을 개별 또는 모두 읽음 처리하고 연결된 사진이나 1:1 대화로 바로 이동할 수 있다.
- 활성 1:1 대화는 12초 간격으로 갱신되며 수신 메시지 읽음 처리, 마지막 발신 메시지의 읽음 표시,
  상대 프로필 이미지, 해시태그 탐색과 최신 메시지 자동 스크롤을 제공한다.
- 사이트 이름과 관리자 연락처 설정을 사용하는 `/support` 안내 페이지와 푸터 링크를 추가했다.

## GOAPI

- 공개 사진가 통계 API를 추가했다. 본인 전용 작품 스튜디오의 접근 권한과 응답 계약은 유지한다.
- 메시지 읽음 시각과 읽음 갱신 API, 최대 2,000자 메시지 저장을 지원한다.
- 모바일 Google 로그인은 공식 validator로 서명·만료·audience·이메일 인증을 검증한다.
- 모바일 Sign in with Apple의 nonce·계정 연결 검증과, 계정 삭제 전 Apple 토큰 폐기 흐름을 추가했다.
- iOS의 업로드 출처와 Firebase 푸시 발송을 지원하고 개별 푸시 실패 로그를 보완했다.
  Apple 인증·삭제와 모바일 푸시는 해당 기능을 사용하는 운영자가 `env.sample`의 선택 설정을
  구성해야 한다. 네이티브 앱 자체는 이 웹·서버 릴리스에 포함되지 않는다.

## v1.3.1에서 업데이트

**DB migration이 필요하다.** 업적·업로드 출처·OAuth identity/nonce 테이블, 메시지의 `read_at` 컬럼과
인덱스 및 2,000자 메시지 컬럼을 준비한다. 기존 첫 게시글·첫 댓글 이력은 업적으로 보정한다.
`install`은 기존 설치에서도 반복 실행할 수 있다.

1. 데이터베이스, 업로드 파일, `.env`와 기존 runtime을 백업하고 운영 중인 GOAPI·Node 프로세스를 중지한다.
2. 로컬 수정 사항을 보존하면서 소스를 v1.3.2로 갱신한다. `.env`는 덮어쓰지 않고 `env.sample`과 비교해
   `GOAPI_VERSION=1.3.2`, `NUXT_PUBLIC_VERSION=1.3.2`를 반영한다.
3. NUBO 작업 디렉터리에서 다음 명령을 실행한다.

```bash
./bin/nubo update --dry-run
./bin/nubo update
./bin/nubo download --dry-run
./bin/nubo download
NUBO_ENV_FILE="$PWD/.env" ./bin/goapi install
npm ci
npm run build
```

4. 기존 tmux·PM2 등에서 GOAPI와 Node를 재시작하고 로그인·사진 목록·알림·메시지 동작을 확인한다.
   Node는 `npm start`로 실행한다. 직접 실행할 경우에도 반드시 production 설정을 지정한다.

```bash
NODE_ENV=production node --env-file=.env .output/server/index.mjs
```

`nubo update`와 `download`는 Git, DB migration, 웹 빌드나 실행 중인 서비스를 자동으로 변경하지 않는다.
이미 중간 버전의 migration을 적용한 사이트도 이번 runtime을 기준으로 확인한다.

runtime 배치와 libvips 동적 링크 검사를 통과한 파일만 게시한다.
