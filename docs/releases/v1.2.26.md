# NUBO v1.2.26

NUBO v1.2.26은 권한을 다시 확인하는 원본 이미지 감상 경로와 두 가지 advance 스킨을 추가하고, 로그인 기반 Market 리뷰를 정식 통합 릴리스에 포함합니다. 이 버전부터 하나의 제품으로 설치되는 NUBO와 GOAPI의 공개 버전을 동일하게 맞추며, 릴리스 manifest에는 재현 가능한 정확한 소스 commit을 계속 기록합니다.

## 주요 변경사항

### 원본 파일 주소를 숨기는 사진 감상

- 게시물 조회 권한을 확인한 뒤 2분 동안만 유효한 스트림 URL을 발급해 원본 이미지를 표시합니다.
- 파일의 실제 저장 경로와 직접 URL은 게시글 응답과 브라우저에 노출하지 않습니다.
- 보기 레벨·포인트 잔액, 비밀글, 삭제글, 작성자 차단과 파일 소유 관계를 원본 요청에서도 다시 확인합니다. 게시글 열람 때 처리한 보기 포인트는 중복 차감하지 않습니다.
- 인라인 표시와 HTTP byte range를 지원해 큰 사진도 브라우저에서 효율적으로 감상할 수 있습니다.

### nubo-advance-gallery 0.2.0

- Unsplash의 정갈한 목록과 500px의 집중 감상 흐름에서 영감을 받은 웜톤 masonry 갤러리를 추가했습니다.
- 미리보기를 누르면 원본을 지연 로드하는 전체 화면 뷰어가 열립니다. 화면 맞춤·1:1 전환, 키보드와 모바일 스와이프 탐색, 배경·Esc 닫기를 지원합니다.
- 목록·상세·작성·수정 화면과 댓글·답글·첨부 관리를 스킨 안에 독립적으로 구현했습니다.
- 기존 `nubo-basic-gallery`는 호환 기준선으로 그대로 유지합니다.

### nubo-advance-blog 0.1.0

- Medium의 읽기 흐름에서 영감을 받은 대표 글과 에디토리얼 피드, 좁은 본문과 넓은 표지 레이아웃을 추가했습니다.
- 읽기 진행률, 본문 목차, 코드 복사와 댓글·답글 관리를 제공합니다.
- 큰 제목 중심의 작성·수정 화면을 포함하며 네 라우트를 다른 게시판 스킨에 의존하지 않고 소유합니다.
- 기존 `nubo-basic-blog`는 호환 기준선으로 그대로 유지합니다.

### 로그인 기반 스킨 리뷰와 별점

- nubohub.org 로그인 사용자는 스킨마다 계정당 리뷰 하나를 작성하고 수정할 수 있습니다.
- 별점은 1~5점, 리뷰 본문은 10~2000자이며 공개 목록·상세에서 평점과 리뷰를 확인할 수 있습니다.
- 운영자는 리뷰를 영구 삭제하지 않고 숨김·복원할 수 있으며, 숨긴 리뷰는 평점 집계에서 제외됩니다.
- 사용자 확인에는 최소한의 uid·닉네임·관리자 여부만 전달하고 Market은 NUBO 로그인 토큰을 저장하지 않습니다.

### 통합 버전 정책

- NUBO Web과 GOAPI의 공개 버전을 모두 1.2.26으로 맞췄습니다.
- 이후 통합 릴리스도 두 구성 요소의 공개 버전을 동일하게 유지해 사용자가 호환 표를 따로 확인하지 않도록 합니다.
- 재현성과 감사 가능성을 위해 릴리스 manifest에는 NUBO와 GOAPI의 정확한 commit, API contract와 빌드 상태를 계속 기록합니다.

## 업데이트 방법

공식 설치를 사용 중이라면 NUBO checkout에서 다음 순서로 업데이트합니다.

```bash
nuboctl update --dry-run
nuboctl update
nuboctl status
```

GOAPI가 변경되는 업데이트 전에는 데이터베이스와 업로드 파일을 운영 환경의 정책에 따라 별도로 백업해야 합니다. 등록된 사이트 전용 스킨은 새 공식 릴리스를 기준으로 자동 재빌드·재적용됩니다.

커스텀 Web 빌드는 기본 Node heap 1536 MiB를 사용합니다. 실제 메모리 부족이 확인된 경우에만 서버 여유 메모리를 확인한 뒤 `NODE_OPTIONS=--max-old-space-size=<MiB>`를 상향하세요.

## 지원 범위

- 공식 prebuilt: Ubuntu 22.04 이상 amd64, Node.js 22 이상, systemd, Nginx, MySQL/MariaDB 단일 서버
- Nginx HTTP 설정은 nuboctl이 지원하지만 TLS 인증서와 외부 DB·메일 제공자 설정은 운영자 영역입니다.
- 데이터베이스와 업로드 파일의 자동 백업·복원은 제공하지 않습니다.
