# 어드밴스 갤러리 스킨

Unsplash 계열의 여백과 사진 중심 목록, 500px 계열의 집중 감상 화면에서 영감을 받은 독립 스킨이다.
`nubo-basic-gallery`를 수정하거나 import하지 않으며 NUBO provider·공통 UI·타입만 사용한다.

## 첫 계약

- 목록과 일반 상세 화면은 `f*.webp` 대형 미리보기를 사용한다.
- 사진 클릭 시 `originalImageUrl(fileUid)`로 권한 확인된 2분짜리 원본 스트림을 발급받는다.
- 전체화면에서 사진 클릭은 화면 맞춤과 1:1 원본 크기를 전환한다.
- 닫기, 배경 클릭, `Esc`, 좌우 키와 화면 버튼으로 원래 흐름에 복귀·탐색한다.
- 원본 저장 경로는 스킨과 게시글 JSON에 전달하지 않는다.

`GalleryList`, `GalleryView`, `GalleryWrite`, `GalleryModify`를 모두 자체 소유하므로 기본 스킨이 없어도
동작하는 패키지를 유지한다. 초기 0.1.0은 목록·원본 뷰어 골격과 간결한 작성·수정 흐름을 우선하며,
댓글 작성과 모바일 제스처의 세부 완성도는 다음 작업 단위에서 다듬는다.
