# nubo-advance-home

TSBOARD v1.3.0의 Reddit형 홈 피드를 NUBO 홈 스킨 계약에 맞게 발전시킨 통합 피드다. 별도 API를
추가하지 않고 홈 provider가 제공하는 게시글, 게시판 메뉴, 검색, 페이지 추가 로딩과 좋아요 기능을
사용한다.

## 주요 동작

- 데스크톱에서는 투표 레일, 본문 중심 피드와 게시판 탐색 레일을 함께 표시한다.
- 모바일에서는 투표 기능을 카드 하단에 두고 우측 레일을 숨겨 한 열로 읽는다.
- `미디어` 필터는 현재 불러온 게시글 중 커버 이미지가 있는 글만 모아 보여준다.
- 커버 이미지를 누르면 피드의 미디어만 이어 보는 전체화면 뷰어를 연다.
- 전체화면 뷰어는 화면 맞춤과 1:1 보기, 마우스 드래그, 좌우 키·버튼·모바일 스와이프,
  `Escape` 닫기와 포커스 복원을 지원한다.

## 파일 경계

이 스킨은 다른 스킨 폴더를 import하지 않는다. 플랫폼 공통 `NuboHomeContext`, 타입, UI 컴포넌트와
composable만 사용하므로 독립 패키지로 배포할 수 있다.
