# 어드밴스 블로그 스킨

Medium 계열의 차분한 읽기 흐름과 에디토리얼 피드에서 영감을 받은 독립 블로그 스킨이다.
특정 서비스의 자산이나 화면을 복제하지 않으며 `nubo-basic-layout`의 웜톤 라이트·다크 색상과
NUBO provider 계약을 사용한다.

## 화면 계약

- 목록은 현재 페이지 첫 글을 대표 글로, 나머지를 표지와 요약이 있는 에디토리얼 피드로 보여준다.
- 상세는 좁은 본문 폭, 넓은 표지, 읽기 진행률, 데스크톱 목차와 글 반응 도구를 제공한다.
- 본문 HTML은 정제한 뒤 출력하며 코드 블록은 강조 표시와 복사를 지원한다.
- 작성·수정은 큰 제목과 플랫폼 공용 Tiptap 도구막대, 표, 붙여넣기·드롭 이미지 업로드와 임시글 복원을 지원한다.
- 댓글 작성·답글·수정·삭제와 기존 첨부 미리보기·삭제를 스킨 안에서 완결한다.

`BlogList`, `BlogView`, `BlogWrite`, `BlogModify`를 모두 자체 소유하고 다른 스킨 폴더를 import하지
않는다. 필요한 공유 경계는 NUBO provider, 타입과 플랫폼 공통 UI뿐이다.

본문 편집은 `~/components/editor/NuboTiptapEditor.vue`를 사용한다. 스킨 안에 별도 Tiptap 구현을
두지 않으며 자세한 사용 계약은 `docs/SKIN_EDITOR.md`를 따른다.

0.1.0은 NUBO 1.2.26의 writable editor·첨부·댓글 provider 계약을 기준으로 하는 첫 브라우저 QA
후보 버전이다.
